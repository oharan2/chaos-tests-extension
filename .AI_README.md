# AI Agent Instructions
## Project Overview
This repository is the Krkn chaos OpenShift Tests Extension product. Canonical location: `github.com/RedHatQE/chaos-tests-extension`. It wraps krkn-hub; it does not rewrite Krkn. It is not a fork of a `redhat-chaos` copy of this tree, and it does not live in `openshift-eng/openshift-tests-extension`.

Binary: `cmd/chaos-tests`. Suites: `chaos/disruption/pod` (11 specs) and `chaos/disruption/node` (9 specs). All first-slice specs start informing. Main technologies: Go (OTE adapter), JSON scenario registry, bash wrapper, composite `images/Dockerfile.ci`.

## Architectural Notes
- Production flow is: OTE spec → `ote_wrapper.sh` → hub `prow_run.sh` → `run_kraken.py`. Each scenario is a JSON object in `test/chaos/krkn_scenarios.json`. The Go adapter is scenario-agnostic.
- Adapter (`pkg/adapter`): production specs use `Entrypoint`; `ScriptPath` is unit-test only. Isolation Conflict+Taint `chaos-disruption`.
- Registry: `test/chaos/krkn_scenarios.json` (20 informing specs). Snapshot: `.openshift-tests-extension/openshift_external_chaos.json`. Adding a scenario is another JSON object, not a Python test file.
- Wrapper `images/ote_wrapper.sh` replaces Prow `*-commands.sh`. It loads ES/telemetry/AWS from secret mounts (fail-closed), then `exec`s hub `prow_run.sh`.
- Image `images/Dockerfile.ci` is a composite: `ext-builder` produces `/usr/bin/chaos-tests-ext.gz`; `prow-scripts` supplies krkn-hub; final `FROM tests`.
- The two suites in `cmd/chaos-tests/main.go` are standalone:
  - `chaos/disruption/pod` (30m TestTimeout)
  - `chaos/disruption/node` (60m)
  `Parallelism: 1`. No `Parents`; do not nest under `openshift/conformance/*`.
